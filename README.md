# Silent Auction Program 🏆

A beginner-friendly Python project that simulates a silent auction system where multiple users can place bids anonymously. The program collects bidder names and bid amounts, stores them using dictionaries, and announces the highest bidder at the end.

---

## 🚀 Features

* Accepts bids from multiple users
* Stores bidder information securely during the auction
* Automatically finds the highest bidder
* Simple command-line interaction
* Beginner-friendly project for practicing Python fundamentals

---
